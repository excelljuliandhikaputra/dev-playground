## 👋 About

Hi! I'm **Excell**, a first-year **D4 Informatics Engineering** student at **Universitas Airlangga**.
My course uses both **Python** and **Java**, so I practice the fundamentals of both here,
one topic at a time, until they stick.

Each topic has three parts:

| Part | What it is |
|------|------------|
| 📖 **Basics** | A lesson file with short explanations and runnable examples |
| ✍️ **Unsolved** | Practice exercises with an empty space for my own code |
| ✅ **Solved** | My own answers, checked against the expected output |

> [!NOTE]
> All explanations and comments are written in **English 🇬🇧 and Indonesian 🇮🇩**. The code itself is always in English.

## 🚀 How to Use

**1. Clone the repo**
```bash
git clone https://github.com/excelljuliandhikaputra/dev-playground.git
cd dev-playground
```

**2. Read a lesson**
```bash
cd python/01-print
python print_basics.py
```
```bash
cd java/01-output
java OutputBasics.java
```

**3. Try the exercises yourself**

Open any `*_exercises_unsolved.py` or `*ExercisesUnsolved.java` file, write your code under each exercise,
run it, and compare your result with the **Expected output** in the file. From Python topic 06 and
Java topic 07 onward, each exercise file has a built-in checker that prints `[TODO]`, `[FAIL]`, or `[PASS]`.

> [!TIP]
> Try solving it on your own first before opening the `solved` file. Getting stuck is part of learning.

## 📏 My Learning Rules

1. **Only use what I've learned so far.** No jumping ahead to concepts from later topics.
2. **No hardcoding.** Always print from variables, never type the answer directly.
3. **Output must match exactly.** Every space, comma, and capital letter counts.
4. **Self-check.** Change the input data and run again. If the output doesn't change, something is hardcoded.
